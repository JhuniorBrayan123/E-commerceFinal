🔐 Prueba de Registro - Auth Service

Esta prueba creará un usuario en MySQL local a través del auth-service

📋 Instrucciones:
  1. Haz clic en "Registrar Usuario"
  2. Abre MySQL Workbench
  3. Ejecuta: SELECT * FROM auth_db.users ORDER BY created_at DESC LIMIT 1;
  4. Deberías ver el usuario recién creado
